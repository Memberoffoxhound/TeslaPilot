# iPilot

This folder holds the plan for iPilot, a personal iPhone app that can show live camera and driving data from a TeslaPilot comma.

The in-fork streaming service will be our own clean implementation, written from scratch in TeslaPilot and turned off by default. CommaView (RhynoTech) code is unlicensed and is not copied here.

See `docs/plan.md` for the first-build plan.
